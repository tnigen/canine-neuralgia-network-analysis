Interpretation
--------------
The observed LCC is the largest group of mapped canine neuralgia proteins that are mutually reachable using only interactions among proteins in the supplied disease set. The log-binning null distribution consists of equally sized randomized node sets sampled from similar network-degree bins. The Z-score measures how many null standard deviations the observed LCC lies above or below the null mean. The empirical upper-tail p-value is the fraction of randomized LCCs at least as large as the observed LCC. NetMedPy returned p=0 because none of the 10,000 randomized LCCs was at least as large as observed; the finite-simulation resolution supports reporting this as empirical p<0.0001 alongside the exact output.

The observed LCC (1784 proteins) is larger than the null expectation (1597.179) and is significant at alpha=0.05. This supports treating the mapped canine neuralgia proteins as a topologically coherent disease module for subsequent network-medicine analyses. It does not establish drug efficacy or drug-disease proximity.

Methodological limitations
--------------------------
This is a topological disease-module validation, not evidence of causality, drug efficacy, or drug-disease proximity. STRING associations are not necessarily direct physical interactions and can reflect heterogeneous evidence. Using the supplied full STRING links file without an additional threshold preserves the requested input but can make the network dense. Results depend on interactome coverage, disease-ID coverage, database ascertainment, and the selected approximate degree-bin null model. The graph is undirected and context-free, so tissue, temporal, cell-type, directionality, and interaction-sign information are not modeled. Monte Carlo p-value precision is limited by 10000 iterations.
