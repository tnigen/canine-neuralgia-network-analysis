# Repository contents

| Path | Purpose |
| --- | --- |
| `map_drug_targets_to_dog_biomart.py` | Mapping and quality-control pipeline |
| `requirements.txt` | Python dependency ranges |
| `README.md` | Installation and usage instructions |
| `METHODS.md` | Computational method and inclusion criteria |
| `CITATION.cff` | Machine-readable citation metadata |
| `LICENSE` | MIT software license |
| `RESULT_SHA256SUMS` | Checksums for the archived results |
| `results/drug_target_dog_one2one.csv` | Network-ready drug-target mappings |
| `results/drug_target_dog_one2one.xlsx` | Excel copy of the network-ready mappings |
| `results/drug_target_mapping_qc.xlsx` | Mapping audit records |
| `results/drug_target_mapping_summary.xlsx` | Per-drug mapping statistics |
| `results/mapping_run_metadata.txt` | Archived run provenance |

The source input used for the archived results is intentionally not distributed. Its checksum is recorded in the run metadata so authorized copies can be verified without exposing the original file.
